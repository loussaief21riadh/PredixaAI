## Artificial Intelligence Lottery Analysis Platform

Predixa AI Enterprise is a professional Artificial Intelligence platform designed to analyze historical lottery data, generate advanced statistical insights, train Machine Learning models, and provide prediction services through a modern REST API.

This project demonstrates professional software engineering practices including:

- Machine Learning
- Data Science
- FastAPI
- Software Architecture
- REST API Development
- Database Design
- Flutter Integration
- DevOps Ready

# Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/PredixaAI.git
```

Backend

```bash
cd backend

python -m venv .venv

source .venv/bin/activate

python -m pip install -r requirements.txt
```

Run

```bash
python -m uvicorn app.main:app --reload
```
